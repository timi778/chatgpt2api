# 2026-07-08 工作日志

## OpenAI/Auth0 注册流程 create_account 修复

### 问题
`create_account` 阶段返回 `registration_disallowed`，邮箱创建/提交密码/验证码全通过但最终创建失败。

### 根因
1. 注册流程缺少 `authorize/continue` 步骤（邮箱提交阶段）
2. `create_account` 请求只带了 `OpenAI-Sentinel-Token`，缺少 `OpenAI-Sentinel-SO-Token`
3. SO token 来源在 Sentinel /req 返回的 `so` 字段，生成方式和 PoW 类似

### 修改文件
- **utils/sentinel.py**: 新增 `build_sentinel_tokens()` 返回 `(sentinel_token, so_token)`；新增 `_request_sentinel_req()`、`_generate_so_token()`；SO token 支持 PoW(seed/difficulty) 和 turnstile(dx) 两种方式；5000ms observer 等待；SDK 版本常量 `SENTINEL_SDK_VERSION="20260124ceb8"`。注意：turnstile dx 的 XOR 密钥用 requirements_token（gAAAAAC 前缀），不是 PoW 解。
- **services/register/domain_stats.py**: 新建。按 provider+domain 分组统计注册成功率，自动停用低成功率域名（默认 min_attempts=5, min_success_rate=0.2）。存储在 `data/register_domain_stats.json`。
- **services/register/openai_register.py**: 
  - 新增 `_authorize_continue()` 方法，在 `register()` 的 `_platform_authorize` 之后、`_register_user` 之前调用
  - `_create_account()` 改用 `build_sentinel_tokens()` 同时设置 `openai-sentinel-token` 和 `openai-sentinel-so-token` header
  - `register()` 集成 domain_stats：检查域名是否停用、记录成功/失败统计
  - `worker()` 失败后调用 `auto_disable_low_success()` 自动停用低成功率域名
  - 日志记录 token 长度、SDK 版本、so-token 是否生成（不打印明文）
- **api/register.py**: 新增 4 个 domain-stats API 端点（GET 查看、POST 停用/启用/自动停用）

### 验证
- 所有 5 个 register_proxy_runtime 测试通过
- domain_stats 模块功能测试通过
- SO token 生成测试通过（PoW/turnstile/None 三种情况）
- 注意：turnstile dx 的 XOR 密钥是 requirements_token，不是 p_value（PoW 解）

### 后续
- 部署后观察成功率：从 ~0% 提升到 ~50% 说明协议修复有效
- 剩余 registration_disallowed 按邮箱 provider/domain 分组排查，停用低成功率域名
